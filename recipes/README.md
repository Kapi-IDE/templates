# Recipes

Process and architecture playbooks that implement Backwards Build methodology. This directory consolidates strategic planning, system design, implementation runbooks, project-management templates, and cross-cutting frameworks.

```
recipes/
├── strategic/
├── system-design/
├── implementation/
├── ai-specific/
├── project-management/
└── cross-cutting/
```

Each recipe should document audience, prerequisites, and the Backwards Build phase(s) it supports. YAML recipes should include metadata blocks; Markdown templates should provide copy-ready sections.
