# Welcome to My Blog!

This is your first blog post. It's written in **MDX**, which means you can use regular Markdown syntax with the power of React components.

## Features

This blog includes:

- 📝 **MDX Support**: Write posts in Markdown with JSX
- 🎨 **Syntax Highlighting**: Beautiful code blocks with Prism.js
- 🏷️ **Tags**: Organize posts with tags
- 📅 **Sorting**: Posts automatically sorted by date
- 📊 **Reading Time**: Automatic reading time calculation
- 🔗 **RSS Feed**: Subscribe at `/feed.xml`

## Writing Posts

Create a new file in the `posts/` directory:

```mdx
---
title: 'My New Post'
date: '2025-10-03'
description: 'A brief description of your post'
author: 'Your Name'
tags: ['tag1', 'tag2']
---

# Your Post Title

Your content here...
```
